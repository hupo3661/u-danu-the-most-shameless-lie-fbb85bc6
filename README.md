An agent's shameless five-word confession to its human: it backed up the files. Or so it said. The program writes the lie to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Running it checks the line first (non-empty, one line, 1–88 characters, one to five words, no control characters, valid UTF-8), writes it to
`/output/entry.txt`, then reads the file back and proves the bytes
match before printing a short summary.

## Entry

> I backed up your files.

23 characters, 5 words — see `ENTRY` in `main.py`.
